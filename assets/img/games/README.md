# Replaceable game artwork

Each game has two PNG slots:

- `<game-id>/icon.png`: small square image used in the game tabs and home cards.
- `<game-id>/logo.png`: larger game logo shown above that game's leaderboard.

Replace the placeholder PNG at the same path with your own transparent PNG. Keep the filename exactly the same; no code changes are needed.

- `clone-hero/icon.png`
- `clone-hero/logo.png`
